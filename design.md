# Design Philosophy

## Visual Language
- **Modern Civic Design**: Clean, professional aesthetic suitable for government/public service applications
- **Data-Driven Interface**: Emphasize clarity and accessibility of complex property information
- **Trustworthy Authority**: Design conveys reliability and official capacity

## Color Palette
- **Primary**: Deep forest green (#2D5016) - representing Rockingham County's natural landscape
- **Secondary**: Warm gold (#B8860B) - highlighting important information
- **Accent**: Soft blue (#4A90A4) - for interactive elements and data visualization
- **Neutral**: Warm grays and whites for background and text

## Typography
- **Display Font**: Tiempos Headline - for headings and important information
- **Body Font**: Suisse Int'l - for data, descriptions, and interface text
- **Monospace**: JetBrains Mono - for property IDs and technical data

## Visual Effects
- **Aurora Gradient Flow**: Subtle animated background using shader-park
- **Data Visualization**: ECharts.js for interactive property charts and trends
- **Smooth Transitions**: Anime.js for elegant interface animations
- **Hover Effects**: 3D tilt effects on property cards using CSS transforms
